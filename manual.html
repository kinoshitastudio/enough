01

インストール

Chrome ウェブストアから無料で追加できます。Google アカウントは不要です。

1

Chrome ウェブストアを開く

ENOUGH のページを Chrome で開く。スマートフォンからは追加できないので、PC の Chrome から行ってください。

2

「Chrome に追加」をクリック

青い「Chrome に追加」ボタンをクリックすると確認ダイアログが表示される。

3

「拡張機能を追加」で確定

ダイアログで「拡張機能を追加」をクリック。これでインストール完了。

必要な権限について： ENOUGH は SNS サイトの特定ページにのみアクセスします。ブラウザ履歴・パスワード・個人情報を収集しません。プライバシーポリシー →
02

ツールバーにピン留め

設定を素早く開くために、ツールバーにピン留めしておくことをおすすめします。

1

パズルピースアイコンをクリック

Chrome のアドレスバー右側にある拡張機能アイコン（パズルのピース）をクリック。

2

ENOUGH のピンアイコンをクリック

一覧から「ENOUGH」を見つけ、右側のピン留めアイコン（📌）をクリック。ツールバーに表示される。

03

メッセージのカスタマイズ

SNS を開いた瞬間に表示される言葉を、あなた自身のものに変えられます。

デフォルトメッセージ

数字は、あなたじゃない。

1

ツールバーの ENOUGH アイコンをクリック

ポップアップが開く。

2

「あなたのメッセージ」欄を書き換える

テキストボックスに好きな言葉を入力する。例：「今日、何が大事だったか？」「作ることに集中する。」

3

「保存」をクリック

次回から SNS を開くと、新しい言葉が表示される。

04

表示時間の設定

メッセージを何秒表示するか設定できます。デフォルトは 5秒。

1

ポップアップの「表示時間」スライダーを動かす

1秒〜30秒の範囲で調整できる。短すぎると効果が薄く、長すぎると邪魔に感じることも。3〜7秒が使いやすい。

メッセージが表示されている間は、SNS のコンテンツは見えません。時間が来ると自動で消えます。スキップボタンで飛ばすことも可能。
05

数字を非表示にする（任意）

メッセージの介入だけでなく、いいね数・フォロワー数・再生回数をページから完全に消すこともできます。

1

ポップアップの「数字を隠す」トグルをオンにする

該当のページを開くと、メトリクスが非表示になる。いつでも元に戻せる。

注意： この機能はサイトごとに個別に設定できます。X(Twitter)だけ隠す、Instagram だけ隠す、という使い方も可能。
06

対応サイト

X (Twitter) — x.com 対応中
Instagram — instagram.com 対応中
YouTube — youtube.com 対応予定
Threads — threads.net 対応予定
07

よくある質問

メッセージをスキップできますか？

はい。表示中の画面でスキップボタンをクリックすれば、すぐに SNS のコンテンツに移れます。

拡張機能を一時的にオフにできますか？

はい。ポップアップの上部にオン/オフのトグルがあります。

個人情報は収集されますか？

収集しません。すべての設定はブラウザのローカルストレージにのみ保存されます。外部サーバーへの通信は一切ありません。

スマートフォンの Chrome でも使えますか？

残念ながら、Chrome 拡張機能はスマートフォンの Chrome では動作しません。PC の Chrome でご利用ください。

アンインストール方法は？

Chrome のツールバーにある ENOUGH アイコンを右クリック →「Chrome から削除」で削除できます。

まだインストールしていない方へ。

無料。アカウント不要。30秒で始められます。
